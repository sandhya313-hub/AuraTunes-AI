# 🎧 AuraTunes

AuraTunes is an AI-powered emotional music companion that understands feelings and transforms them into immersive multilingual soundtrack experiences.

✨ Features:
- Emotion Detection AI
- Personalized Music Recommendations
- Multilingual Playlists
- Emotional Reflection Responses
- Cinematic UI Experience
- Dynamic Emotion Themes

🛠️ Built Using:
- Python
- Streamlit
- HuggingFace Transformers
- Spotify API

🌌 AuraTunes creates a calm emotional space where music gently connects with human feelings.
